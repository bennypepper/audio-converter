Audio Converter (Portable Windows Edition)
=========================================

1. EXTRACT THE WHOLE FOLDER:
   Do not run AudioConverter.exe directly from inside the ZIP preview window.
   Right-click the downloaded zip and choose "Extract All".

2. RUNNING THE APP:
   - Double-click AudioConverter.exe to open the interactive wizard.
   - Or drag and drop any audio file or music folder directly onto AudioConverter.exe.
   - Keep AudioConverter.exe, ffmpeg.exe, and the _internal folder together in this folder.

3. WINDOWS SMARTSCREEN:
   Because this executable is independently built and unsigned, Windows Defender
   SmartScreen may display "Windows protected your PC". Click "More info" and then
   "Run anyway".
